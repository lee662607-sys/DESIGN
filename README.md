# Lee · Design Portfolio

个人设计作品集网页预览，纯静态 HTML/CSS/JavaScript，无需安装依赖。

首屏以独立三维作品卡片，在分散漂浮、环形册页、倾斜矩阵之间连续变换；下滑进入 4px 窄缝、无圆角瀑布流。支持暂停/重播、降动效偏好、手机布局及作品放大查看。

## GitHub Pages

在仓库 Settings → Pages 中设置：

- Source: Deploy from a branch
- Branch: gh-pages
- Folder: /(root)

保存并等待 GitHub 部署完成。默认预期网址：
https://lee662607-sys.github.io/DESIGN/

## 预览素材与边界

当前只有一个真实案例《图鉴湘江》湖南湘江新区成立十周年纪念画册。多个视图均归属同一项目，不是多个独立案例。

assets 内四张图片是依据用户作品视觉生成的独立构图示意，并非原稿逐像素复本；正式作品集应替换为原始图片。书中文字、地图和标志等细节尚未由可读取的原稿验证。

动画依据用户提供的拍屏视频重建可见机制；原站触发方式和精确参数无法仅由视频确认，本预览采用滚动控制。
